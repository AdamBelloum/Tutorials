    Introduction to AI

    Welcome to this four-parts tutorial on Artificial Intelligence. This repository contains the lecture slides, thematic breakdowns, and hands-on programming materials designed to trace the evolution of AI: from the early logic-based paradigms of the 1950s to modern data-driven learning engines.

    Tutorial Objectives

    This series bridges the conceptual gap between classical mathematics, statistical learning, and empirical implementations. By completing this tutorial, you will be able to: * Deconstruct Classical Systems: Recognize the power and structural ceilings of logic-bound Symbolic AI. * Master Optimization Mechanics: Explain how mathematical mappings use loss landscapes and gradient tracking to auto-calibrate internal representations. * Navigate Complexity and Geometry: Reason about data transformation matrices, parametric capacities, and non-linear boundaries. * Evaluate & Implement Responsibly: Diagnose generalization errors (underfitting/overfitting) and actively audit algorithms for data-driven historical biases.

    Tutorial structure

    Module 1: The Old Way – Symbolic AI

    • Focus: Logic engines, Good Old-Fashioned AI (GOFAI), structural bottlenecks, and the philosophical turn toward learning from data.
    • Core Concepts: Physical Symbol System Hypothesis, expert systems, brittle failure modes, and the emergence of the AI Winter.
    • Assets: Slide Deck

    Module 2: Foundations of Machine Learning

    • Focus: Data-driven mapping, classical parametric and non-parametric estimators, space transformations, and geometric optimization.
    • Core Concepts: Generalization boundaries, loss functions (MSE, Cross-Entropy), gradient descent kinetics, and performance validation.
    • Assets: Slide Deck

    Module 3: Introduction to Deep Learning

    • Focus: Multi-layered artificial neural networks (ANNs), hierarchical feature learning, representation tracking, and advanced sequence topologies.
    • Core Concepts: Backpropagation mechanics, gradient dissipation/explosion anomalies, activation non-linearities, CNNs, RNNs, and Self-Attention Transformers.
    • Assets: Slide Deck

    How to Navigate This Tutorial

    1. Conceptual Alignment: Review the slide decks listed in each module to ground yourself in analytical concepts.
    2. Modular Deep-Dives: Explore each dedicated folder via its specific README file to engage with key discussion questions, reading lists, and mental models.
    3. Hands-On Application: Launch the interactive programming session in Module 2 to visualize boundaries shifting dynamically via Python.
