# Module 1: The Old Way – Symbolic AI

##  Overview
This module investigates **Symbolic AI** (or Good Old-Fashioned AI), a paradigm that treats cognition as the syntactic manipulation of explicit symbols using rigid logic rules. We trace its historical scale, economic triumphs, structural bottlenecks, and ultimate collision with real-world uncertainty.

##  Learning Objectives
* Define the **Physical Symbol System Hypothesis** and its implications for generalized intelligence.
* Contrast top-down rule systems with bottom-up learning methodologies.
* Diagnose why rule-based networks undergo brittle failures when exposed to noisy, out-of-domain data.
* Analyze the economic and systemic limits that induced the classical **Knowledge Acquisition Bottleneck**.

##  Core Theoretical Focus
* **Symbols and Syntax:** Mapping entities (`CAT`, `DISEASE_X`) to conditional logical structures (`IF condition THEN conclusion`).
* **The Scale Frontier:** Case studies in deterministic expert networks (Dendral, MYCIN, XCON) and structural game search (Deep Blue).
* **Systemic Failure Loops:** Cascading rule contradictions, exponential maintenance costs, and the subsequent systemic funding collapses known as "AI Winters."
