# Workshop: hands-on on OpenStack User interface
---


Welcome! This repository contains all the materials for the hands-on on OpenStack User interface. Whether you are here to learn or to lead, this guide will get you started.

## Objective

The goal of this tutorial is to provide hands-on experience in:

* Navigating cloud management interfaces
* Managing the Virtual Machine (VM) lifecycle
* Interacting with Cloud APIs
* Operating within resource constraints
